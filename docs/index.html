Tải binary về, mở trình duyệt, dùng. TikTok, Reels, YouTube Shorts, Facebook, Instagram, Threads, X — render song song, đúng safe-zone từng nền tảng.

Tinh túy gói trong 1 trang

Mọi thứ xử lý trên máy bạn. Ngoại lệ duy nhất: phụ đề tự động (ASR) gửi audio tới dịch vụ online — không bật thì không có file nào rời máy.

🎬

Ghép video + audio

Nhiều clip kéo–thả, nhiều file audio nối tiếp. Video tự lặp cho hết bài, cắt đúng thời lượng, bỏ tiếng gốc.

🎵

Tách âm thanh MP3

Mới ở 0.5.0 — preset xuất MP3 320 kbps từ audio đã ghép. Chỉ chọn mỗi preset này thì không cần video.

🏷️

Tên sản phẩm

File tải về mang đúng tên bạn nhập — giữ dấu tiếng Việt, tự né tên cấm, trùng tên tự thành " (2)".

🗄️

Giới hạn lưu trữ

Kho video 5 GB / 200 file mặc định, tự dọn file cũ nhất, kiểm tra đĩa trước render, thanh dung lượng ngay trong UI.

💬

Phụ đề burn-in

Tự động nhận diện giọng nói (ASR) hoặc dùng file .srt — burn thẳng vào video, màu tuỳ chỉnh.

👀

Xem trước trực tiếp

Khung đúng tỉ lệ preset + safe-zone + chữ + watermark render bằng CSS — chưa cần ffmpeg.

✍️

Chữ & watermark

Font upload, viền, vị trí, hẹn giờ. Watermark di chuyển 4 góc chống crop, tự né safe-zone.

🎚️

Visualizer sóng âm

Sóng / thanh / spectrum chạy theo audio thật — màu, độ cao, độ mờ tuỳ chỉnh.

🌗

Dark / Light / Mobile

Theo hệ điều hành, responsive từ 375px, giao diện tiếng Việt, 1 luồng tuyến tính 5 bước.
